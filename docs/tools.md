# Tools Required

> **Prices are from 2014** and are listed in GBP as originally documented.
> Supplier links were eBay and Halfords listings and are long dead; the items
> are all still commonly available.

## Tools

If you don't already own these, you're going to have to acquire them.

| Item | Cost |
|---|---|
| Set of side cutters (150/200/250 mm) | £14.95 |
| Pick set (6 pc extra long reach hook/pick, O-ring seal remover) | £4.55 |
| Wire strippers | £15.99 |
| Vehicle glass removal tool | £14.26 |
| Hot glue gun | £5.99 |
| Soldering kit (iron, stand, solder, pump) | £9.99 |
| Gasket scrapers | £19.99 |
| CST100 crimpers | £17.00 |
| Craft knife set | £13.25 |
| Set of spring clamps (6 × 4″) | £3.89 |
| Crimping set (273 pc) | £9.99 |

**Plus, not on the original list but needed:**

- **Torx T-20 bit** — for the six headlight face plate screws
- **An oven** — for [splitting the headlights](guides/headlight-splitting.md)
- **8 mm spanner or socket** — battery terminals
- **Philips screwdriver** — engine bay fuse box lid
- **Multimeter** — essential for [tuning the PSU voltage](guides/power-supply.md#tuning-the-voltage)
- **Latex gloves** — handling reflectors and lenses without leaving marks
- Spanners and sockets for [bumper removal](guides/bumper-removal.md)

## Consumables

| Item | Cost |
|---|---|
| Gorilla Glue (60 ml multi-purpose waterproof adhesive) | £3.99 |
| Seam sealant (PU panel bonder, flexible) | £5.99 |
| 3M glass cleaning wipes (25 pack, microfibre) | £1.99 |
| Tiny cable ties | £1.99 |

The seam sealant is what reseals the headlight after the rings are in. The
Gorilla Glue is for tacking the rings into the lenses — optional, as they're a
tight fit.
