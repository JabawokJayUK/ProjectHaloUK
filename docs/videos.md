# Videos

## Effects and ring tests

The startup fade sequence, and the colour-temperature comparison that settled which rings to use.

- [Project Halo — Alpha — Startup effects](https://www.youtube.com/watch?v=248dNoFAD7A)
- [Project Halo — 6K Rings Test](https://www.youtube.com/watch?v=dSU7cvTWB_Q)
- [Project Halo — 8K Rings Test](https://www.youtube.com/watch?v=7mJIelXVpTg)

The 6000 K and 8000 K tests are worth watching back to back — 8000 K reads noticeably
bluer. See [Parts List](parts-list.md) for the ring sizes and the colour decision.
